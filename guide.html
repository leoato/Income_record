재무부 장관 — 사용 안내

내 자산을 '국정'처럼 운영하는 개인 재무 기록 앱 · 지원 문의: leoato@naver.com

매달 말 자산 화면을 캡처해 올리면, AI가 계좌별 잔액을 읽어 정리하고 전월 대비 변화를 담은 '장관 브리핑'을 써 줍니다. 모든 기록은 기기에만 저장됩니다.

처음 시작하기

  1. 둘러보기 — 장관 탭 → 키 없이 데모로 둘러보기. 가상 자료로 모든 화면을 미리 볼 수 있어요.
  2. API 키 등록 — 설정(⚙) → AI API 키. Gemini·ChatGPT·Claude 중 하나만 있으면 됩니다.
  3. 월말 정산 — 장관 탭 → 정산 시작 → 자산 화면 캡처 선택 → 판독 결과 확인 → 브리핑 받기.

API 키는 어디서 받나요

  • Gemini — aistudio.google.com/apikey (키가 AQ. 또는 AIza로 시작)
  • ChatGPT — platform.openai.com/api-keys (sk-로 시작)
  • Claude — console.anthropic.com (sk-ant-로 시작)
키를 붙여넣고 검증을 누르면 어느 회사 키인지 자동으로 알아보고, 그 계정이 쓸 수 있는 가장 최신 모델을 골라 줍니다. 키는 이 기기에만 저장되며 앱 제작자에게 전송되지 않습니다.

자주 묻는 질문

Q. 요금이 드나요?

앱은 무료입니다. AI 사용료는 이용자가 등록한 본인 API 계정으로 청구됩니다(월말 정산 1회는 보통 소액). 키를 넣지 않으면 AI 기능만 잠기고 기록·통계는 그대로 씁니다.

Q. 데이터는 어디에 저장되나요?

기기 안에만 저장됩니다. 서버도 계정도 없습니다. 기기를 바꾸거나 앱을 지우면 사라지니 설정 → 전체 백업(JSON)으로 파일을 보관하세요. 새 기기에서는 백업 복원으로 되돌립니다.

Q. 캡처를 올렸는데 합계가 안 맞아요.

판독 확인 화면에서 숫자를 직접 고칠 수 있습니다. 합계가 캡처의 '총 자산'과 일치해야 다음으로 넘어가도록 막아 두었습니다 — 잘못된 숫자가 기록에 남지 않게 하기 위해서입니다.

Q. '키가 유효하지 않다'고 나옵니다.

키가 잘린 채 복사됐거나, 사용 제한(웹사이트·IP 제한)이 걸린 키일 수 있습니다. 앱이 알려주는 문구에 원인이 함께 표시되니 그대로 따라 해 보세요. 그래도 안 되면 새 키를 발급해 주세요.

Q. 어떤 모델을 쓰나요?

등록한 키의 계정에서 쓸 수 있는 모델 목록을 받아 최신·상위 모델을 자동으로 고릅니다. 모델이 단종되면 다음 요청 때 자동으로 다시 고릅니다.

Q. 데모 데이터를 지우고 싶어요.

설정 → 데모 → 데모 데이터 지우기. 내 기록만 남습니다.
