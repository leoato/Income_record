개인정보처리방침

앱 이름: 재무부 장관 · 최종 수정일: 2026년 8월 19일

재무부 장관(이하 "앱")은 개인 자산과 수입을 스스로 기록·점검하기 위한 도구입니다. 앱을 만든 사람은 이용자의 어떤 데이터도 수집하거나 저장하지 않습니다.

1. 앱이 운영하는 서버는 없습니다

앱에는 회원가입·로그인이 없고, 개발자가 운영하는 서버도 없습니다. 이용자가 입력한 모든 기록은 이용자 기기 안에만 저장됩니다.

  • 수입 기록, 자산 스냅샷, 계좌 목록, 목표, 브리핑, 메모
  • 이용자가 입력한 AI API 키
저장 위치는 기기 내부 저장소(WebView localStorage)입니다. 앱을 삭제하면 이 데이터도 함께 사라지므로, 필요하면 앱의 설정 → 전체 백업으로 파일을 따로 보관하세요.

2. AI 기능을 쓸 때 전송되는 정보

앱의 정산·브리핑·집무실 대화 기능은 이용자 본인이 발급한 API 키로 이용자가 선택한 AI 사업자에게 직접 요청을 보냅니다. 개발자의 서버를 거치지 않습니다.

  • 선택 가능한 사업자: Google(Gemini), OpenAI(ChatGPT), Anthropic(Claude) — 이용자가 키를 넣은 곳 한 곳
  • 전송되는 내용: 이용자가 정산에 올린 자산 화면 캡처 이미지, 자산·수입 숫자, 이용자가 적은 특이사항 메모
  • 전송되지 않는 것: 이름·연락처·이메일·기기 식별자·위치 (앱이 이 정보를 다루지 않습니다)

전송된 내용의 처리·보관은 해당 AI 사업자의 정책을 따릅니다. 각 사업자의 개인정보처리방침을 확인하세요. AI 기능을 쓰지 않으면(키를 넣지 않으면) 어떤 데이터도 기기 밖으로 나가지 않습니다.

3. 수집하지 않는 것

  • 광고 식별자, 분석·추적 도구를 일절 사용하지 않습니다
  • 제3자에게 데이터를 판매·공유하지 않습니다
  • 이용자를 식별할 수 있는 계정 정보를 만들지 않습니다

4. 사진 접근

월말 정산에서 자산 화면 캡처를 올릴 때만 사진 선택 화면이 열립니다. 이용자가 직접 고른 이미지만 앱이 읽으며, 사진 보관함 전체를 읽거나 따로 저장하지 않습니다.

5. 미성년자

앱은 특정 연령대를 겨냥하지 않으며, 아동의 개인정보를 의도적으로 수집하지 않습니다. 애초에 개발자가 어떤 이용자 정보도 수집하지 않습니다.

6. 이용자의 권리

모든 데이터가 기기에만 있으므로, 삭제·수정·내보내기를 이용자가 직접 완전히 통제합니다.

  • 개별 기록 삭제: 각 화면에서 직접 삭제
  • 전체 삭제: 설정 → 전체 삭제
  • 내보내기: 설정 → 전체 백업(JSON) / 자산 CSV 내보내기
  • API 키 삭제: 설정 → 키 삭제
